Litos A Simple & Modern Blog Theme for Astro

Litos is a clean and modern Astro blog theme focused on content presentation and reading experience. More than just a blog, it's a personal space to showcase your skills, projects, and life.

Built with Tailwind CSS for elegant responsive design and React components for smooth interactions. Features light/dark theme switching, multiple article layouts, GitHub contribution charts, and more. Inspired by@needim, redesigned by@Dnzzk2 based on Astro.
